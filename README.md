# OKTOPLUS — mise en ligne gratuite

1. Crée un compte sur [github.com](https://github.com/signup).
2. **New repository**, public, nommé exactement **oktoplus**.
3. Glisse **tous** les fichiers de cette archive à la racine du dépôt (pas dans un sous-dossier).
4. **Settings → Pages** → Branch **main**, dossier **/ (root)** → Save.
5. Ton site : `https://TON-PSEUDO.github.io/oktoplus/`

Les musiques et clips restent sur SoundCloud, YouTube et Google Drive.
Pour un fichier Drive : Partager → Toute personne disposant du lien → Lecteur.

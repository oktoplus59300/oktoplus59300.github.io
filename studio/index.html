Mettre la page en ligne

GitHub Pages héberge le site gratuitement, sans prestataire. Tes MP3 et clips restent sur Drive, SoundCloud ou YouTube.

  1. 1. Crée un compte gratuit sur github.com.
  2. 2. Nouveau dépôt public nommé exactement oktoplus.
  3. 3. Glisse tous les fichiers de l’archive GitHub Pages à la racine du dépôt.
  4. 4. Settings → Pages → Branch main, dossier / (root) → Save.
  5. 5. L’adresse devient https://oktoplus59300.github.io/

Ajouter un morceau ou un clip

Pour un fichier Drive : Partager → Toute personne disposant du lien → Lecteur, puis coller le lien. YouTube et SoundCloud marchent aussi.

Les ajouts de ce formulaire restent sur cet appareil (aperçu personnel). Le catalogue public ci-contre est déjà constitué de tes titres SoundCloud et de tes clips YouTube.
